# Agent Run Logs

One file per agent run, created from [`../_templates/run-log.md`](../_templates/run-log.md) and named:

```text
YYYY-MM-DD-<agent>-<topic>.md
e.g. 2026-11-10-company-discovery-b2b-saas.md
     2026-11-12-product-analysis-batch-01.md
```

A run log records what the agent searched, which records it created, updated or skipped, what went wrong, and what a human needs to review. It is the audit trail for the discovery data, and the input for the "qualified companies researched/week" KPI.

Full rules: [discovery/README.md](../README.md).
