# AGENTS.md

Guidance for AI coding agents working in this repository.

## Languages: English is the default page

Every public page opens in **English by default**. Other languages are alternates at a subfolder.

- **SOHA site:**
  - English is the root page, `site/index.html`.
  - Persian is the source in `site/fa/`, and Turkish is in `site/tr/`.
  - The English and Turkish pages are generated by `tools/i18n/build.py`.
- **Client proposals:** English is `site/proposals/<client>/index.html`. A second language lives at `site/proposals/<client>/<lang>/index.html`, for example `site/proposals/biletino/tr/`.
  - This applies even when the client is local and the brief asks for their language first, for example a Turkish brief.
  - In that case, build both languages and still make English the default.
- **Every language version has:**
  - its own `<html lang>`, canonical URL and social preview image
  - `hreflang` alternates for each language, plus `x-default` pointing to the English page
  - a small language switch (for example **EN / TR**) in the top bar that keeps the current section (`#s3`)
- **Demo strings:** text created by scripts (labels, toasts, generated copy, dates) follows the page language from `<html lang>`. Client and place names keep their own spelling in every language, for example "Düğün.com" and "Defne Köşkü".

## Publishing

`site/` deploys to GitHub Pages on every push to `main`. Do not push, publish or deploy without the user's explicit approval for that push.
